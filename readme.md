# IoT and Networking Practical End-Term Submission

This repository contains implementations for various IoT, system administration, and computer vision pipelines.

## Project Directories
* **Kafka_linux**: Automated log processing pipeline with bash monitoring.
* **Mqtt_Redis**: Message broker setup with database caching.
* **MultiChat System**: Client-server socket chatting framework.
* **Opencv_UDP**: Real-time video streaming with edge detection over UDP sockets.
